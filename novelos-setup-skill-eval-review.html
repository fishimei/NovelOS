novelos-setup-skill 测试用例审阅

这是为本次 skill 修改准备的轻量审阅页。完整 benchmark 可以后续再跑；当前重点是确认这些真实提示是否覆盖你要的流程。

Eval 1：赛博修仙初始化并准备创作

Prompt: 我想写一个赛博修仙的小说，底层灰修黑进天道那种，帮我初始化 NovelOS 设定，确认后保存并开始第一轮创作。

Expected: 拆解需求，用白话展示世界、开局、角色、关系、第一变量、演绎片段、导入前汇总，并在确认前不调用 API。

Eval 2：缺主角方向时少量追问

Prompt: 帮我做一个民国志怪悬疑群像的 NovelOS setup，但我还没想好主角是谁。你先拆一下，推理不出来的再问我，别直接提交。

Expected: 主动推断大部分设定，只对会改变方向的点追问 1-3 个问题，不问卷化，并明确不会提交。

Eval 3：确认提交、自动发现 API、只创建 story session

Prompt: 确认提交刚才那版设定到 NovelOS。项目在本地 D:\creation\NovelOS，服务地址如果你能自动发现就用现有 API。提交完帮我创建 story session，但先别跑正文。

Expected: 验证确认状态，从项目文档/路由发现 API，不猜 URL 或 token；缺 base URL/project ID 时追问；只通过 API 保存；创建 story session，但不调用 story advance。
